# Контрольные вопросы

## 1. Чем `File.WriteAllText` отличается от `File.AppendAllText` с точки зрения существующего содержимого файла?
-`WriteAllText` полностью перезаписывает файл, а `AppendAllText` дописывает данные в конец существующего файла.

## 2. Что возвращает `File.ReadAllLines` — какой тип данных, и как это связано с темой массивов?
-Возвращает массив строк. Каждая строка файла становится отдельным элементом этого массива.

## 3. Зачем нужна конструкция `using` при работе с `StreamWriter`/`StreamReader`? Что произойдёт, если её не использовать и забыть закрыть поток вручную?
-Автоматически закрывает поток и освобождает файл. Без неё файл останется заблокированным ОС, что приведёт к ошибкам доступа.

## 4. Как связана идея `using` с блоком `finally`?
-using — это сокращение для блока try-finally, которое гарантирует вызов Dispose() даже при возникновении исключений.

## 5. Зачем использовать `Path.Combine` вместо ручной конкатенации пути через `+`?
-Для кроссплатформенности: она сама подставляет правильные разделители путей

## 6. Какие два типа исключений упомянуты в этой работе как специфичные для файловых операций, и чем они отличаются друг от друга по смыслу?
- FileNotFoundException (файл не найден) и DirectoryNotFoundException (не найдена папка, в которой он должен лежать).
